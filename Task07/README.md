# Task 07 – Procedural vs Object-Oriented

**Compiler:** Microsoft Visual C++ (MSVC), C++17

**Compile OOP:** `cl /std:c++17 /W4 /EHsc smart_card.cpp`  
**Run:** execute the corresponding `.exe` file.
