# Task 01 – OOP Analysis

This folder contains the Task 01 written analysis and UML class diagram for the Namma Metro Smart-Card Fare System assignment.

## Files
- `analysis.md` – Complete written response, object justifications, OOP principles, constraints, complexity comparison and assumptions.
- `uml_class_diagram.mmd` – Mermaid class diagram source.

## UML preview
The UML file uses Mermaid `classDiagram` syntax. It can be previewed in a Mermaid-compatible Markdown viewer or GitHub if embedded in a Markdown file.

## Notes
The assignment does not specify student/senior concession rates or the order in which concession and peak surcharge are applied. These are explicitly left unspecified rather than assumed.
